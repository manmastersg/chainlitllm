# MPP Series

**Summary**: Detailed specifications and features of the Telestream PRISM MPP series.

**Sources**: raw/Video Test and Monitoring Equipment.md

**Last updated**: 2026-05-25

---

The **MPP Series** provides a 1RU full-rack form factor for the Telestream PRISM line. These instruments are highly space-efficient, making them ideal for dense rack environments where footprint is a critical consideration.

### Models Overview

All MPP models feature **4 x 12G SDI inputs with SDI loop-through outputs**.

- **MPP-100**: 1RU, Full-rack. SDI Waveform Monitor with SDI loop-through outputs. Requires an external display. (SDI only)
- **MPP-200**: 1RU, Full-rack. SDI and IP Waveform Monitor with SDI loop-through outputs and eight-channel analog output (2 x SFP+ for 10GE; 25GE requires 25GE license). Requires an external display.
- **MPP-300**: 1RU, Full-rack. SDI and IP Waveform Monitor with SDI EYE base unit, SDI loop-through outputs, and eight-channel analog output (2 x SFP+ for 10GE; 25GE requires 25GE license). Requires an external display.

### Physical Characteristics

- **Height**: 4.4 cm (1.73 in.)
- **Width**: 48.3 cm (19.01 in.)
- **Depth (inc. Connectors)**: 31.3 cm (12.32 in.)
- **Weight**: 3.5 Kg - 3.6 Kg (7.72 - 7.94 lbs.)

### Key Features

- **Form Factor**: 1RU, Full-rack.
- **Display**: All models require an external display.
- **SDI Inputs**: 4 x 12G SDI inputs with loop-through on all models.
- **Connectivity**: MPP-200/300 have 2 SFP+ sockets for 10GE (25GE requires 25GE license) and eight-channel analog output.
