# MPD Series

**Summary**: Detailed specifications and features of the Telestream PRISM MPD series.

**Sources**: raw/Video Test and Monitoring Equipment.md

**Last updated**: 2026-05-31

---

The **MPD Series** consists of 3RU full-rack video test and monitoring instruments. These models are designed for standard rack mounting and provide more comprehensive connectivity compared to the MPS series.

### Models Overview

All MPD models feature **4 x 12G SDI inputs**.

- **MPD-100**: 3RU, Full-rack. SDI Waveform Monitor base unit with dual integrated 9" touchscreens. (SDI only)
- **MPD-200**: 3RU, Full-rack. SDI and IP Waveform Monitor with dual integrated 9" touchscreens (2 x SFP+ for 10GE; 25GE requires 25GE license).
- **MPD-300**: 3RU, Full-rack. SDI and IP Waveform Monitor with SDI EYE base unit and dual integrated 9" touchscreens (2 x SFP+ for 10GE; 25GE requires 25GE license).

### Key Features

- **Form Factor**: 3RU, Full-rack.
- **Display**: All MPD models feature dual integrated 9" touchscreens.
- **SDI Inputs**: 4 x 12G SDI inputs on all models.
- **Connectivity**: Supports various SDI and IP input capabilities depending on the model. MPD-200/300 have 2 SFP+ sockets for 10GE (25GE requires 25GE license).
