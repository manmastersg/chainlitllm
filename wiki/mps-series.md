# MPS Series

**Summary**: Detailed specifications and features of the Telestream PRISM MPS series.

**Sources**: raw/Video Test and Monitoring Equipment.md

**Last updated**: 2026-05-31

---

The **MPS Series** is a line of 3RU half-rack video test and monitoring instruments. They are designed for versatility, with models ranging from basic SDI monitoring to advanced SDI and IP capabilities.

### Models Overview

All MPS models feature **4 x 12G SDI inputs**.

- **MPS-100**: 3RU, Half-rack. SDI Waveform Monitor base unit with integrated 9" touchscreen. (SDI only)
- **MPS-200**: 3RU, Half-rack. SDI and IP Waveform Monitor with integrated 9" touchscreen (2 x SFP+ for 10GE; 25GE requires 25GE license).
- **MPS-300**: 3RU, Half-rack. SDI and IP Waveform Monitor with SDI EYE base unit and integrated 9" touchscreen (2 x SFP+ for 10GE; 25GE requires 25GE license).

### Key Features

- **Form Factor**: 3RU, Half-rack.
- **Display**: All models feature a single integrated 9" touchscreen.
- **SDI Inputs**: 4 x 12G SDI inputs on all models.
- **Connectivity**: Supports various SDI and IP input capabilities depending on the model. MPS-200/300 have 2 SFP+ sockets for 10GE (25GE requires 25GE license).
