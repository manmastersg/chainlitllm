# Methods of Operation

**Summary**: A guide to interacting with the Telestream PRISM series, covering physical controls and user interface elements.

**Sources**: raw/PRISM-MPS-MPD-MPP-User-Manual-D00013488R-cc.md

**Last updated**: 2026-05-26

---

This page details the various ways to interact with and operate your PRISM instrument, ranging from physical controls to remote access.

## Physical Interaction

### Touchscreen Operation (MPS & MPD)

The MPS and MPD series feature integrated touchscreens for direct interaction.

- **Gestures**: Use finger touches to select applications, adjust settings, and navigate menus.

### Keyboard and Mouse Operation

The MPD (via external peripherals) and MPP models utilize a keyboard and mouse for full control.

- **Interaction**: Use the mouse to navigate the UI, select tiles, and interact with menus.

### Remote Control Operation

For models without a built-in display (MPP) or when working remotely:

- **VNC/WebRTC**: Use remote access features to control the instrument from a PC.
- **Manual Control**: Remote operation is possible via networked access tools.

## User Interface Elements

Understanding the UI layout is essential for efficient operation.

### Status Bar

Located at the top of the display:

- **Left Side**: Contains icons for instrument settings (Volume, Presets, Settings, Input Type) and the Application Menu.
- **Right Side**: Displays real-time status, including selected input, signal type, reference status, audio channel status, and the clock (Real-time vs. PTP).

### Application Tiles

The main workspace consists of tiles that display different applications:

- **Layouts**: Tiles can be sized as quarter-screen, half-screen, or full-screen.
- **Navigation**: Use the application menu to select and organize tiles.
