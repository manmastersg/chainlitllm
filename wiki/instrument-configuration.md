# Instrument Configuration

**Summary**: A guide to configuring the settings, calibration, and operational parameters of the Telestream PRISM series.

**Sources**: raw/PRISM-MPS-MPD-MPP-User-Manual-D00013488R-cc.md

**Last updated**: 2026-05-26

---

This page covers how to adjust the internal settings and software parameters of your PRISM instrument to ensure accurate monitoring and optimal operation.

## Input & Signal Configuration

Ensure the input signal matches your measurement needs through these settings:

- **Virtual Inputs**: Configure and select software-defined virtual inputs.
- **HDR/WCG Monitoring**: Adjust settings for High Dynamic Range and Wide Color Gamut monitoring.
- **Timecode Decoding**: Configure the instrument to decode external timecode signals.
- **Reference Settings**: Set up analog or digital reference (Genlock/Sync) for instrument locking.

## Audio & Output Configuration

- **Audio Settings**: Adjust volume, balance, and specific audio measurement parameters.
- **Instrument Outputs**: Configure how the instrument sends out signals (e.g., via AUX OUT or loop-through).

## System & Maintenance

- **Display Settings**: Adjust brightness, contrast, and UI element layout.
- **Time and Date**: Set the internal clock and time zone for accurate logging.
- **Firmware & Software**: Procedures for upgrading the instrument's firmware and managing software licenses.
- **Logging & Alarms**: Configure system logging (Syslog) and set up user-defined alarms for monitoring.

## Advanced Settings

- **NMOS**: Configuration and discovery of NMOS (Networked Media Open Specifications)-enabled devices.
- **PTP (Precision Time Protocol)**: Manage PTP synchronization and timing-related settings.
