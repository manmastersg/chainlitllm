# PRISM Options

**Summary**: A comprehensive guide to the software options, hardware options, accessories, and ordering information for the Telestream PRISM series.

**Sources**: raw/Video Test and Monitoring Equipment.md

**Last updated**: 2026-05-31

---

The Telestream PRISM series offers various software licenses, hardware options, and accessories to expand its capabilities. Options are ordered with the prefix `MPSDP-` (e.g., FMT-4K becomes MPSDP-FMT-4K).

## Application Summary

Applications are grouped into four tiers based on model support.

### Standard Applications (All Models)

All PRISM models include these applications by default:

- Waveform, Vector, Diamond, Lightning, Picture
- Video Session, Event Log, Timing, Ext Ref
- IP Status, Audio

### Optional Applications (All Models)

These optional applications can be added to any PRISM model:

- Stop Display, CIE, CAM (Camera Alignment)
- Channel (Audio Channel Status), Dolby Status
- Datalist, ANC Session, AV Delay
- SDI Generator

### Optional Applications for IP-Capable Models (MPS-200/300, MPD-200/300, MPP-200/300)

- PIT Histogram, IP Session, Stream Timing
- IP Graphs, PTP Graphs, IP/SDI Generator

### Physical Layer Applications (Standard on -300 models; MPS-300, MPD-300, MPP-300)

- Eye Pattern, Jitter

| **GEN**\*      | SDI/IP signal generator; includes IP/SDI Generator application                                                                                                             | SDI Generator, IP/SDI Generator                                 |
| **PROD**\*     | Production feature sets: Stop display, Light meter, HDR/WCG Conversion, Luma Qualified CIE chart                                                                           | Stop Display, CIE                                               |
| **MULTI**\*    | Multi-channel IP/SDI input and Camera Alignment Monitoring                                                                                                                 | CAM                                                             |
| **EXTNDSP**\*  | Extended desktop support (MPS and MPP models only)                                                                                                                         | —                                                               |
| **IP-MEAS**\*  | IP Measurement feature sets: IP/PTP Graph, IP/PTP Session, PIT Histogram, Timing, Stream Timing and Stream capture                                                         | PIT Histogram, IP Session, Stream Timing, IP Graphs, PTP Graphs |
| **JPXS**\*\*\* | ST 2110-22 (JPEG XS) support on PRISM MPS, MPD, and MPP models                                                                                                             | —                                                               |

\*Requires prefix MPSDP- for ordering.
\*\* ENG-QC requires specific model support.
\*\*\* A combination of JPXS + MULTI license enables 4x JPEG XS decoding. A combination of JPXS + GEN license enables JPEG XS test signal generation.
