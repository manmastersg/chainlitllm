# Application Catalog

**Summary**: A comprehensive index of the software applications available on the Telestream PRISM series, categorized by their primary function.

**Sources**: raw/PRISM-MPS-MPD-MPP-User-Manual-D00013488R-cc.md

**Last updated**: 2026-05-31

---

The PRISM series features a wide array of specialized software applications for monitoring, analysis, and signal generation. This catalog provides an overview of the available tools.

## Video & Waveform Applications

These applications are used for visual analysis of video signals, including timing, waveform, and color accuracy.

| Application               | Description                                                                    |
| ------------------------- | ------------------------------------------------------------------------------ |
| **Waveform Application**  | Provides detailed waveform measurements (Luma, etc.) for video analysis.       |
| **Vector Application**    | Used for colorimetry and vector scope-based color analysis (e.g., CIE, Gamut). |
| **Lightning Application** | Specialized for lightning/sparkle analysis and video quality inspection.       |
| **Diamond Application**   | Used for advanced colorimetric/diamond-based analysis.                         |
| **CIE Application**       | Focused on CIE color space measurements and gamut coverage.                    |

## IP & Network Applications

These applications focus on the monitoring and management of IP-based video transport (ST 2110, etc.).

| Application                   | Description                                                               |
| ----------------------------- | ------------------------------------------------------------------------- |
| **IP Status Application**     | Provides real-time status of IP network connectivity and health.          |
| **IP Session Application**    | Manages active IP video sessions, including stream properties and timing. |
| **IP Graphs Application**     | Visualizes IP network traffic, including throughput and latency graphs.   |
| **PIT Histogram Application** | Analytical tool for IP packet jitter and buffer/timing analysis.          |
| **PTP Graphs Application**    | Visualizes Precision Time Protocol (PTP)-related timing and sync data.    |

## Audio & Signal Applications

Tools for monitoring audio-specific metadata, timing, and signal generation.

| Application                        | Description                                                   |
| ---------------------------------- | ------------------------------------------------------------- |
| **Audio Application**              | Provides audio level, phase, and channel-specific monitoring. |
| **Dolby Status Application**       | Displays Dolby E/D metadata and audio status.                 |
| **AES Channel Status Application** | Monitors AES/EBU-related metadata and status.                 |
| **Channel Application**            | Multi-channel audio level display and analysis.               |
| **SDI Generator Application**      | Generates SDI signals for testing and calibration.            |
| **IP/SDI Generator Application**   | Generates both SDI and IP signals for testing.                |
| **Stream Timing Application**      | Analyzes stream-specific timing and arrival metrics.          |
| **Timing Application**             | Dedicated tool for signal timing and sync analysis.           |

## Specialized QC & Metadata Applications

Advanced tools for specific professional broadcast requirements.

| Application                   | Description                                                    |
| ----------------------------- | -------------------------------------------------------------- |
| **Stop Display Application**  | Provides a frozen-frame view for analysis and metadata review. |
| **CAM Application**           | Used for camera alignment and color-matching tasks.            |
| **Picture Application**       | General-purpose capture and review of still frames/images.     |
| **Video Session Application** | Manages ongoing video sessions and stream-level data.          |
| **Event Log Application**     | Provides access to system logs, alarms, and historical events. |
| **Capture Application**       | Manages the capturing of video/audio files and screenshots.    |
| **Datalist Application**      | Displays detailed packet-level data for analysis.              |
| **ANC Session Application**   | Monitors and decodes ANC (Auxiliary Data) embedded in SDI.     |
| **AV Delay Application**      | Measures audio-to-video delay/lip-sync.                        |
